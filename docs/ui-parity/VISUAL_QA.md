第一轮登录对照：卡片间距小于原 APK，通用阴影使文字和输入框出现投影。提交 `496c5a6` 修正行高、输入框间距、底部装饰圆位置及阴影的作用范围。41982432296 截图复看确认白卡内文字不再有阴影，结构和空白更接近 APK。字体字形、系统栏和软键盘仍有平台差异。

复拍白卡同一相对列的高度：原 APK 453.5 dp，iOS 454.0 pt；起点分别约 224.4 dp 与 224.0 pt。测量使用 Android Pixel 5 模拟器 1080×2340（2.75 px/dp）及 iPhone 17 Pro 模拟器 1206×2622（3 px/pt）。这是结构尺寸核对，未将不同平台屏幕直接作逐像素相等断言。

视觉夹具只渲染生产组件，不登录、不写真实订单、不连接设备或请求扣款。登录用真实运行的 iOS 应用做无账号交互，仅提交格式无效的手机号触发本地校验。只有真实 iOS 应用截图被描述为整页运行截图；用纯显示值渲染的其余图是组件验收证据。没有取得原 APK 登录后状态的实际截图时，不能用源代码参数或编译通过代替逐图验收。
